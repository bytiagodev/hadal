# Hadal

> 🚧 Work in progress. Early-stage build, nothing here is final.

A scroll-driven descent from the ocean surface to the bottom of the Challenger Deep, 10,935 metres down.

The page is the ocean. Scroll position maps to real depth. Light fades zone by zone, real creatures appear at their true depths, and a fixed instrument panel reports live depth, pressure, temperature, and remaining light.

Built with HTML, CSS, and vanilla JavaScript. No frameworks, no build step.
